# 演奏タイムライン Lite — 無料体験版

購入前に操作感を確認するための独立した静的HTMLデモです。

## 体験できること
- 現在時刻表示、サンプル公演の時間進行と現在位置ライン
- 曲順確認、表示サイズ変更、デモ進行のリセット
- ストップウォッチと準備カウントダウン（PRE TIMER）
- TAPテンポ、簡易メトロノーム
- マイク使用を許可した場合の簡易チューナー（A=440/441/442Hz）
- 対応ブラウザでの画面点灯保持

## 製品版との違い
公演の新規作成・編集・保存、JSON入出力、ライブラリ、録音・録画、ライセンス認証は含みません。体験版の簡易チューナー等は製品版と同一の精度や動作を保証するものではありません。
